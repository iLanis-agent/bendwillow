# Bendwillow 1.0 TEST
Native Java/Canvas Android 8+ numbered-knee Sashigane variant.

Fence the entire grid into one-cell-wide L regions. Both straight arms extend at least one cell beyond the knee. Every circled number marks the knee of its L and gives the total number of cells in that region. Unclued L regions are allowed. This numbered-knee edition has no arrow clues. Tap internal edges to add or remove fences; no extra fence may split a region without separating it. Twelve unique 4x4 clue boards have twelve distinct partitions.

Saved bend palette and region colors, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.
